# CloudDocs Media Worker Skeleton

Python worker structure for the asynchronous media pipeline described in the root README.

## Files

- `src/worker.py` - orchestration entry point.
- `src/settings.py` - configuration shape.
- `src/messages.py` - queue message function names.
- `src/storage.py` - object storage function names.
- `src/transcoder.py` - FFmpeg/transcoding function names.
- `src/database.py` - video status update function names.

## Status

These files are intentionally placeholders. Add dependencies and implementation only when the worker behavior is ready to be built.
